# v2026.11.20

## Analysis

- Overview table columns can now be shown, hidden, and reordered from the columns button in the table header. Layouts are saved separately for PvE and PvP encounters
- New optional overview columns: damage and heal crit, boss damage and DPS, healing taken (total, HTPS, EHTPS), effective healing, EDTPS, absorbed, defense and shield percent
- Effect uptime table now shows effects as rows and targets as columns, with class and effect icons in the titles and source → target in the timeline
- Challenge bars are now scaled to the top player
- Switching encounters no longer briefly shows incorrect values or shifts the page layout while the new data loads

## Overlay Settings

- Redesigned the overlay settings panel. Each overlay now has a single "Override Global Settings" block
- Metric overlays can now override the shared metric options individually
- Added corner radius option for metric bars (global and per overlay)
- Bar spacing can now be adjusted in 1% steps

## Editors

- Reworked the layout of the encounter, timer, and effect editors: aligned list rows, clearer toggles, and trigger fields nested under the trigger type
- Phase, counter, and other id pickers now show names alongside ids
- Encounter editor sidebar no longer reloads its lists every time it is opened

## Changelog

- The update popup now shows every version released since the one you last viewed
- Full changelog history is available from the Links menu

## Bugfix

- New installs now detect the default combat log directory on first run, including Steam and Flatpak Steam installs on Linux
- New installs now start with the correct default lockout display setting
- Overlays now repaint immediately when style, font, or size settings change
