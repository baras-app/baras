# v2026.11.22

## Parsely Percentiles

- Operation boss kills are now rated against Parsely's data for each player's discipline. Percentiles appear next to DPS, Boss DPS, HPS, EHPS, DTPS and APM in the overview table, and each kill in the encounter list shows its kill time percentile
- Hover a percentile to see how many parses it is based on and how old the data is
- Can be turned off in Settings

## Analysis

- View tabs are now grouped and wrap instead of being cut off in a narrow window
- Empty tables now say why they are empty, and more column headers and controls have tooltips
- The rotation view builds as soon as a starting ability is picked
- Combat log Find steps through matches with Enter and Shift+Enter
- The PvP match table can be sorted, and clicking a row opens the match
- Added keyboard shortcuts for switching encounters and views, listed in Settings
- Smoother charts, clearer chart time labels, and larger small text

## Log Files

- Logs that start mid-session after a crash or disconnect are now tagged and linked to the log they continue from. In open-world areas the previous log's area and character carry over
- The log file list shows PvP map badges, accepts filter keywords (nim, hm, sm, fp, pvp, arena, warzone, dc), and remembers its filter
- The log file list opens faster with large log directories

## Overlays and Profiles

- Turning overlays on or off and moving them now saves to the active profile automatically
- Unsaved appearance changes are flagged in the overlay settings panel, with a Discard button next to Save
- Deleting a profile or saving over a different profile now asks for confirmation, and the last profile can no longer be deleted

## Editors

- User-created bosses and areas can now be deleted from the encounter editor
- Unsaved edits are kept when switching to another tab and back
- Ctrl+S saves the open form
- An ID typed into a list field is added when the field loses focus, not only on Enter
- Timers can no longer be saved without a name or with a zero duration
- The trigger event picker is grouped by kind
- A failed save is now reported and leaves the form marked as unsaved

## Settings

- Hotkeys and Parsely credentials save as they are changed, like the rest of the page

## General

- Error messages now stay on screen until dismissed
- Actions that fail, such as locking overlays or playing a test sound, now say so instead of doing nothing
- The window opens larger on first run
- If the interface crashes, a bar now offers to reload it
- Charts no longer need an internet connection to load

## Bugfix

- The "opening log" banner no longer clears before the log has finished loading
- Saving an open timer or effect form no longer undoes changes made with the row's quick toggles
- The icon preview in the editors no longer flickers or shifts the input
