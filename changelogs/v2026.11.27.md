# v2026.11.27

Combat Replay: watch an operation boss fight or a PvP match play back on the game's own map. The effects editor
has been reworked, and effect customizations now keep up with updates to the built-in effects.

## Replay (new Analysis tab)

Beta - feedback appreciated

- Plays a fight back on the map: where everyone stood, who they were targeting, health, casts, buffs and debuffs
- Available for operation boss fights and for warzone and arena matches
- Maps are downloaded the first time a fight needs them. The app asks before the first download; downloads can be turned off and the stored maps cleared in Settings
- Play, pause, scrub, play at quarter speed, or loop the time range selected in the explorer
- Timeline shows phases, deaths and boss casts. Death recap links jump to the moment before the death
- Click a player or enemy to follow them: a trail of their recent movement, target lines, distance to target and their last ability
- Boss fights open zoomed to the room the fight happened in and follow the raid between rooms. PvP shows the whole zone

## Effects

- Effects editor reworked: filter by class, sort by column, search by name, ID or display text, and enable, disable, mute or export everything in the filtered list at once
- The effect form is laid out as basics, display, alert and sound beside trigger, refresh, duration and modifiers
- Changes to a built-in effect now store only what you changed, so the rest of the effect keeps following updates. Existing customizations are converted on first launch; a backup is kept as `effects.toml.v1.bak`
- Turning an effect or its audio on or off no longer marks it as modified
- `{ability}` and `{effect}` can be used in display and alert text
- New Powertech / Vanguard buffs, off by default. Enable them in the effects editor
- Energy Shield (Mercenary / Commando) no longer shows for Powertech / Vanguard, which has its own entry

## Encounter editor

- Notes can be added to timers, phases, counters, challenges and effects
- "Timer not firing?" button explains what the game does and does not write to the combat log
- Lists have column headers and open sorted by name

## Overlays

- Elements and bars inside overlays default to a 2px corner radius (was 3px)
- Effect icons on the Boss Health overlay are off by default
- Overlay settings: the open overlay's row is highlighted, the settings panel is wider, and per-profile overrides have a reset button back to Global
- Metric overlays: pick a preset first; the template box only appears for Custom

## Interface

- Settings moved to a gear icon in the header
- Raid frame name detection (OCR) has a header button, a Detect Names button on the Overlays page, and one setting that turns the feature and its hotkey on or off
- Raid frame tools only show in the header while raid frames are enabled
- Percentile toggle moved into the Overview columns menu
- Abilities and effects the combat log leaves unnamed are named from game data, shown in brackets
- Taunt marks on the Aggro timeline take the taunter's colour
- Rows and cards fade in as they load instead of the whole page

## Bugfix

- A fight no longer ends early when two players battle rez you at once and one of the casts is cancelled
- Effects with no duration end only when the game removes them
- Several race conditions that could prevent audio from playing properly eliminated
- Refresh path now properly handles all self-buffs
- An effect that was removed is no longer brought back by a later AoE refresh
- No end alert or sound when an effect is cleared by cleanup instead of expiring
- Alerts fired on apply show the ability or effect name in place of the placeholder
- Affliction's discipline filter was ignored
- Trigger type group headers were blank on Linux
