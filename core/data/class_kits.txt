# Per-class effect kits for scripts/gen_class_effects.py, Imperial IDs only; the generator
# adds Republic mirrors. One entry per line:
#
#   <ability ID or -> : <effect IDs or -> : <parts>   # name
#
# parts:
#   buff         duration buff for each listed effect (no effect: times the ability cast)
#   cd           cooldown of the ability (datamined base value)
#   stacks       like buff, refreshed on every stack change
#   @Discipline  restrict to these Imperial disciplines (mirror added); default is every
#                discipline that has the ability
#
# Anything measured differently in logs (durations, modifiers, cooldown start) is an entry
# in class_effect_overrides.toml; a kit entry an override already tracks is skipped.
# Only sections marked (reviewed) are generated; the others are drafts awaiting review.
